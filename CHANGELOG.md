# v1.7 — составы и расстановка перед боем (разработка)

- При запуске сцены можно выбрать по три бойца каждой команды из пяти существующих профилей, включая повторяющиеся типы, и управление красными: ИИ или вручную.
- Перед боем бойцы размещаются на свободных гексах своей зоны: два левых столбца для синих, два правых для красных. Действия и ИИ начинаются только после «Начать бой» и проверки конфигурации.
- P/«Новый бой» возвращает к подготовке. R повторяет принятые составы и позиции; T сохраняет старые ручные дуэли и возвращает пользовательский командный состав. Боевые формулы сохранены.
- 276 новых проверок модели и интеграции; полный прогон — 19/19 файлов, 1455 проверок, аудит 371/371. Нативный интерфейс проверен через XTest; границы проверки — `docs/V17_VALIDATION.md`.

# v1.6 — простой ИИ красной команды (разработка)

- В командном бою 3×3 красными по умолчанию управляет ИИ, синими — игрок. A переключает красных в ручной режим без сброса. Четыре прежние дуэли остаются ручными.
- Планировщик выбирает законную атаку с наибольшим ожидаемым фактическим уроном, учитывая MP, дальность, HP, уклонение, крит, защиты и материю через существующие формулы. При отсутствии атаки — движение по кратчайшему свободному пути к позиции атаки, иначе пропуск. Выбор не меняет состояние и не расходует случайные броски.
- Одно действие за ход, пауза 0,65 секунды перед ходом ИИ, ожидание анимаций и собственных пропусков контузии. R/T/A сбрасывают ожидание; после победы ИИ прекращает действия. Режим атаки игрока сохраняется.
- Ручные команды активному бойцу ИИ заблокированы; осмотр и управление сценарием доступны. Перемещение игрока и ИИ проходит через общий метод с проверкой BFS и единственным завершением хода.
- Добавлены 190 проверок решений и жизненного цикла ИИ. Сценарий v1.5 явно включает ручной режим для сохранения исходной проверки обеих сторон.
- Реально выполнены 17/17 тестовых файлов, 1179 проверок в Godot 4.6.3; аудит 354/354. Подробности и границы проверки — `docs/V16_VALIDATION.md`.
- База v1.5 с исправлением Inspector уже объединена в main, PR #1, `61eb550`. Окончательный баланс монстров и правило инициативы не менялись.

# v1.5 — командный бой

- Новый сценарий по умолчанию: 3 на 3 с командирами и тестовыми монстрами v1.4. Прежние четыре дуэли сохранены в цикле T, R сбрасывает текущий бой.
- Две команды управляются вручную. Фиксированная чередующаяся очередь, одно действие на собственный ход, раунды после полного обхода. Окончательная инициатива GDD не задаётся.
- Поверженные бойцы удаляются с поля и из очереди; бой продолжается до поражения всей команды. После победы действия блокируются.
- На поле обозначены команды и номера бойцов; справа — полный состав, HP/MP, очередь живых и параметры выбранного бойца.
- Сохранены боевые формулы, материя, физические криты, отсутствие магических критов, два собственных пропуска при контузии и регенерация MP.
- Пустые и повторяющиеся ID не создают лишних слотов очереди. Добавлены 302 проверки очереди и командного боя; старый тест контузии явно выбирает дуэль, тест базового боя использует фиксированные броски вместо случайного уклонения.
- Реальная проверка выполнена в Godot 4.6.3; детали и известное старое падение Inspector — в `docs/V15_VALIDATION.md`.
