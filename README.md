# СУЛЭЙН — v1.9: арены и маршруты

Ветка `codex/v1.9-battle-arenas` продолжает проверенную пользователем v1.8 с подготовкой боя, предпросмотром, ИИ и Web-экспортом. Принятая база в `main` — v1.5 с исправлением Inspector (`61eb550`); разработка v1.9 пока идёт отдельно. Текущий статус: [docs/CHAT_CONTEXT.md](docs/CHAT_CONTEXT.md).

Пошаговый тактический прототип на гексах, Godot 4.3+. Сцена начинается с подготовки **боя 3 на 3**. Выберите по три бойца для каждой команды из пяти профилей: мужчина, женщина, Сокол, Адская гончая, Лич. Повторяющиеся типы разрешены. Затем откройте расстановку, выберите бойца и свободный гекс его зоны: два левых столбца для синих, два правых — для красных. Кнопка «Начать бой» запускает сражение; до неё ИИ, действия и очередь приостановлены. ИИ красных можно отключить флажком при подготовке.

При подготовке можно выбрать тестовую арену: **Открытое поле**, **Два прохода** или **Колонны**. Закрытые гексы отмечены крестом и непроходимы для всех бойцов в текущем прототипе. При наведении на свободный гекс маршрут показывает число шагов и лимит движения; дальний участок маршрута выделяется серым. Выбранная арена сохраняется при R и возврате из старых дуэлей T, а P открывает её в черновике.

Эти схемы не задают окончательные правила карт GDD. Препятствия ограничивают перемещение; укрытия и проверка линии видимости не добавлялись, атаки сохраняют действующие дальности. На полях меньше 7×5 доступны только открытая арена и прежняя расстановка.

Начальный состав:

| Синяя команда | Красная команда |
|---|---|
| С1 — мужчина, булава | К1 — Адская гончая |
| С2 — женщина, копьё | К2 — Сокол |
| С3 — Сокол | К3 — Лич |

В командном бою по умолчанию **игрок управляет синими, ИИ — красными**. Клавиша **A** возвращает ручное управление красными без перезапуска боя. Четыре прежние дуэли остаются ручными. Тестовая очередь: **С1 → К1 → С2 → К2 → С3 → К3**. Каждый живой боец получает одно действие за ход: **движение, атака или пропуск**. После обхода очереди начинается следующий раунд. Это фиксированный порядок демо, окончательное правило инициативы пока не задано.

Павший боец освобождает гекс и исключается из очереди. Победа наступает после поражения **всех** бойцов противоположной команды. После последней анимации открываются итоги: победитель, потери и состояние бойцов. Можно повторить бой, изменить составы или вернуться к полю и журналу; кнопка «Итоги боя» открывает результат снова.

**Управление:**

- ЛКМ по активному бойцу, затем по зелёному гексу для движения или оранжевой цели для атаки. Серое кольцо означает недоступную атаку; наведение объясняет причину.
- Перед атакой панель показывает урон при попадании и крите, их вероятности, средний урон за попытку, MP и дальность. Это прогноз по текущим формулам без бросков RNG и расхода ресурсов; физический удар может промахнуться. Магия в текущем демо не промахивается и не критует.
- Режим можно выбрать кнопками под полем или клавишами 1/2/F. Статус контузии показывает оставшиеся собственные пропуски.
- `1` — обычный физический удар с силой из профиля бойца; `2` — дополнительное умение, если назначено; `F` — магия, если назначена (пока только соседний гекс).
- `Space` — пропуск хода игрока; `M` — тестовый расход 20 MP; `R` — повтор текущего боя с принятыми составами и позициями.
- `P` или «Новый бой» — вернуться к выбору составов и расстановке. Изменения применяются при следующем «Начать бой».
- `A` — переключение ИИ красной команды в бою 3×3. Настройка сохраняется при R/T; в дуэлях обе стороны всегда управляются вручную.
- `T` — цикл из пяти сценариев: командный бой → дуэль с женщиной → Сокол → Адская гончая → Лич → командный бой. Возврат сохраняет принятые составы и расстановку.
- Клик по строке списка справа показывает параметры бойца, включая поверженных. Синие/красные кольца и обозначения С1–К3 различают команды и одинаковых монстров. Очередь живых бойцов отображается над списком.

**Поведение ИИ:** после паузы 0,65 секунды выбирается доступная атака с наибольшим ожидаемым фактическим уроном с учётом уклонения, крита, защиты, материй, HP и MP. При равенстве предпочитается меньший расход MP, затем стабильный порядок целей и режимов. Если атаки нет, боец идёт по кратчайшему свободному пути к позиции атаки, максимум на своё значение движения. Если пути нет — пропускает ход. Движение и атака остаются разными ходами. Лич может применять назначенную магию с прежней дальностью 1 гекс; отдельной дальней атаки не вводится.

Во время хода ИИ ручные команды движения/атак/пропуска/расхода MP красного бойца блокируются. Осмотр бойцов, A, R и T доступны. ИИ ждёт окончания анимации и двух собственных пропусков контузии; после победы действия прекращаются. Выбранный игроком режим атаки сохраняется.

Контузия сохраняет два отдельных пропуска **собственных** ходов с уведомлениями в журнале. Регенерация MP происходит один раз в конце действия или пропуска. Формулы урона, материй, уклонения и крита из v1.4 сохранены.

**Монстры — тестовые, баланс не согласован:**

| Монстр | Материя | Категория | Base PDEF/MDEF | Уклонение |
|---|---|---|---|---|
| Сокол | Воздух | Летающий | 20%/10% | 20% |
| Адская гончая | Огонь | Наземный | 30%/5% | 10% |
| Лич | Тьма | Магический/неживой | 10%/40% | 5% |

У монстров нет брони. При совпадении материй атака −15%; при преимуществе атакующей материи защита цели −15 п.п.; нейтральность отключает взаимодействие.
