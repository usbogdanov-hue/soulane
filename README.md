# СУЛЭЙН — разработка v1.6: ИИ красной команды

База — принятая рабочая v1.5 с исправлением Inspector, объединённая в `main` через PR #1 (`61eb550`). Снимок v1.5 сохранён в `working/v1.5`. Новая v1.6 разрабатывается отдельно в `codex/v1.6-enemy-ai`; пользовательское принятие v1.5 не означает принятия v1.6. Текущий статус: [docs/CHAT_CONTEXT.md](docs/CHAT_CONTEXT.md).

Пошаговый тактический прототип на гексах, Godot 4.3+. По умолчанию запускается **бой 3 на 3**:

| Синяя команда | Красная команда |
|---|---|
| С1 — мужчина, булава | К1 — Адская гончая |
| С2 — женщина, копьё | К2 — Сокол |
| С3 — Сокол | К3 — Лич |

В командном бою по умолчанию **игрок управляет синими, ИИ — красными**. Клавиша **A** возвращает ручное управление красными без перезапуска боя. Четыре прежние дуэли остаются ручными. Тестовая очередь: **С1 → К1 → С2 → К2 → С3 → К3**. Каждый живой боец получает одно действие за ход: **движение, атака или пропуск**. После обхода очереди начинается следующий раунд. Это фиксированный порядок демо, окончательное правило инициативы пока не задано.

Павший боец освобождает гекс и исключается из очереди. Победа наступает после поражения **всех** бойцов противоположной команды. После завершения боя действия заблокированы до перезапуска или смены сценария.

**Управление:**

- ЛКМ по активному бойцу, затем по зелёному гексу для движения или противнику для атаки.
- `1` — обычный физический удар с силой из профиля бойца; `2` — дополнительное умение, если назначено; `F` — магия, если назначена (пока только соседний гекс).
- `Space` — пропуск хода игрока; `M` — тестовый расход 20 MP; `R` — сброс текущего сценария.
- `A` — переключение ИИ красной команды в бою 3×3. Настройка сохраняется при R/T; в дуэлях обе стороны всегда управляются вручную.
- `T` — цикл из пяти сценариев: командный бой → дуэль с женщиной → Сокол → Адская гончая → Лич → командный бой.
- Клик по строке списка справа показывает параметры бойца, включая поверженных. Синие/красные кольца и обозначения С1–К3 различают команды и одинаковых монстров. Очередь живых бойцов отображается над списком.

**Поведение ИИ:** после паузы 0,65 секунды выбирается доступная атака с наибольшим ожидаемым фактическим уроном с учётом уклонения, крита, защиты, материй, HP и MP. При равенстве предпочитается меньший расход MP, затем стабильный порядок целей и режимов. Если атаки нет, боец идёт по кратчайшему свободному пути к позиции атаки, максимум на своё значение движения. Если пути нет — пропускает ход. Движение и атака остаются разными ходами. Лич может применять назначенную магию с прежней дальностью 1 гекс; отдельной дальней атаки не вводится.

Во время хода ИИ ручные команды движения/атак/пропуска/расхода MP красного бойца блокируются. Осмотр бойцов, A, R и T доступны. ИИ ждёт окончания анимации и двух собственных пропусков контузии; после победы действия прекращаются. Выбранный игроком режим атаки сохраняется.

Контузия сохраняет два отдельных пропуска **собственных** ходов с уведомлениями в журнале. Регенерация MP происходит один раз в конце действия или пропуска. Формулы урона, материй, уклонения и крита из v1.4 сохранены.

**Монстры — тестовые, баланс не согласован:**

| Монстр | Материя | Категория | Base PDEF/MDEF | Уклонение |
|---|---|---|---|---|
| Сокол | Воздух | Летающий | 20%/10% | 20% |
| Адская гончая | Огонь | Наземный | 30%/5% | 10% |
| Лич | Тьма | Магический/неживой | 10%/40% | 5% |

У монстров нет брони. При совпадении материй атака −15%; при преимуществе атакующей материи защита цели −15 п.п.; нейтральность отключает взаимодействие.
