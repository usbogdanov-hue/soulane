# СУЛЭЙН — рабочая разработка v1.4

Не требующая постоянной выгрузки архива рабочая сборка с несколькими сценариями проверки монстров. Godot 4.3+.

**Управление:** `T` — циклически сменить противника (женщина → Сокол → Адская гончая → Лич → женщина), `R` — сброс текущего боя, `1` — базовая физическая атака силы 100, `2` — спецумение (если есть), `F` — тест магии (если назначена), `Space` — пропуск хода, ЛКМ — выбор/действие.

**Тестовые монстры, баланс не согласован:**

| Монстр | Материя | Категория | Base PDEF/MDEF | Уклонение |
|---|---|---|---|---|
| Сокол | Воздух | Летающий | 20%/10% | 20% |
| Адская гончая | Огонь | Наземный | 30%/5% | 10% |
| Лич | Тьма | Магический/неживой | 10%/40% | 5% |

Подсчёт материального преимущества: при совпадении материй атака −15%; при преимуществе материи цели −15 п.п. к соответствующей защите; нейтральная сторона отключает взаимодействие. Нет брони у монстров.

**Тесты при наличии Godot:**

```sh
godot --headless --path . --script res://tests/test_v13.gd
godot --headless --path . --script res://tests/test_monsters_v14.gd
```

Здесь Godot недоступен, поэтому сохранён статус непроверенной в движке рабочей ветки, без выгрузки архива.
