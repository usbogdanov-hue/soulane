# Сулэйн — текущая рабочая версия

Этот файл фиксирует принятую базу разработки. Перед новой задачей сверять реальные ветки и PR; история других чатов автоматически не переносится.

## Состояние разработки v1.6

- Рабочая v1.5 с исправлением Inspector принята пользователем и **объединена в `main`**, PR #1, `61eb550`. Снимок принятой базы — `working/v1.5`, `2227e5b`.
- Пользователь выбрал следующий этап: **v1.6 — простой ИИ красной команды**. Реализация находится отдельно в `codex/v1.6-enemy-ai`; не считать её объединённой с `main` или принятой как рабочую без соответствующего решения.
- В v1.6 синими управляет игрок, красными — ИИ после паузы 0,65 секунды. A включает ручной режим, R/T сохраняют настройку и сбрасывают ожидание. Четыре старые дуэли остаются ручными.
- ИИ выбирает законную доступную атаку с наибольшим ожидаемым фактическим уроном; иначе идёт по кратчайшему свободному пути к позиции атаки либо пропускает ход. MP, дальность, одно действие, контузия и победа используют действующие правила.
- Проверки этой ветки: **17/17** тестовых файлов, **1179** проверок, из них 190 новых для ИИ; аудит **354/354**, 223 ссылки. Отчёт — [V16_VALIDATION.md](V16_VALIDATION.md). Это реальные запуски Godot 4.6.3 в ходе разработки v1.6, отдельные от прежних отчётов.
- Организация пяти чатов актуализирована в [PR #2](https://github.com/usbogdanov-hue/soulane/pull/2), `codex/chat-topics`; его статус проверять отдельно. В показанном пользователем интерфейсе нет раздела Projects и команды переноса чата; общие файлы не создают папку в приложении.

## Подтверждённые правила и проверки

Рабочая база v1.5 содержит ручной бой 3×3, одно действие за ход, тестовую очередь С1 → К1 → С2 → К2 → С3 → К3, удаление павших и победу после поражения всей команды. R и T сохраняются. Окончательная инициатива и баланс монстров ещё не утверждены. Действующие ограничения характеристик и боевые правила — в [AGENTS.md](../AGENTS.md); `GDD_MAPPING.md` — исторический v0.8 с устаревшими формулами.

В историческом прогоне v1.5 после исправления Inspector на Godot 4.6.3 прошли **15/15** тестовых файлов, **989** проверок, Inspector **84/84**, статический аудит **334/334**. Импорт и headless-запуск основной сцены — без ошибок скриптов. У пяти старых тестов остаются прежние сообщения RID/ObjectDB/resources при завершении.

Подробности — в [новом отчёте Inspector](INSPECTOR_LEVEL_VALIDATION.md) и [заметках тестирования](topics/testing.md). [Исходный отчёт v1.5](V15_VALIDATION.md) исторический: его 14/15 и два сбоя Inspector не являются текущим результатом исправленного кода.

При сохранении v1.5 тесты повторно не запускались; проверено совпадение кода через Git. Принятие версии пользователем не означает личного запуска: последнее подтверждение такого запуска относится к **v1.2.1**. Именно Godot 4.3 не проверен; текущая проверка v1.6 описана отдельно в её отчёте.
