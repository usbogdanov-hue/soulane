# Сулэйн — общий контекст чатов

Этот файл связывает отдельные чаты по одному проекту. Он не переносит историю переписки: решения, которые нужны другим чатам, записываются в репозиторий и передаются ссылкой на ветку или PR.

## Как начать

1. Открыть [список чатов и готовые стартовые сообщения](CHAT_TOPICS.md).
2. Прочитать корневой `AGENTS.md`, этот файл и заметки выбранной подтемы.
3. Проверить реальное состояние веток, открытых PR и локальных изменений. Сведения ниже — снимок состояния, а не автоматический статус GitHub.
4. Для новой задачи создать отдельную ветку от выбранной актуальной базы. Если несколько чатов работают в одной локальной копии, использовать отдельные worktree/рабочие копии: переключение общей ветки мешает другим чатам.

## Как передавать работу

Одна задача — одна ветка и один PR. Тематический чат может вести несколько последовательных задач; создавать вечную общую ветку для всей подтемы не нужно. Тематические границы помогают найти контекст, но не запрещают необходимые согласованные изменения соседних файлов.

В завершении задачи обновить заметки её подтемы, а при изменении общей версии или правил — этот файл. Записывать результат в своей ветке и указывать PR: другие чаты не видят неотправленные локальные изменения. Не заменять чужие незавершённые правки. При одновременном изменении одного файла согласовать порядок или дождаться нужного PR.

Шаблон передачи:

```text
Подтема и задача:
Базовая ветка / коммит:
Рабочая ветка / коммит / PR:
Что изменено:
Какие решения подтверждены пользователем:
Что остаётся предложением:
Реально выполненные проверки и результат:
Что не проверено / известные ошибки:
Следующий шаг:
```

Этот файл хранит состояние проекта; [заметки основного чата](topics/main.md) — план и общие решения; заметки остальных чатов — подробности своих областей. Утверждённые решения отделять от предложений, а выполненное — от запланированного.
