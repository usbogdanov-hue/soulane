# Сулэйн — чаты по подтемам

Для Сулэйна пользователь создал пять отдельных чатов в интерфейсе Codex. В показанной боковой панели и меню чата нет раздела «Проекты» и команды переноса в проект. Эти файлы сохраняют общий контекст в репозитории; они не создают папку чатов в приложении.

Существующую переписку можно оставить основным чатом. Для нового или заменяющего чата вставить соответствующее стартовое сообщение ниже, затем задать конкретную задачу. История между чатами автоматически не переносится.

Текущая база кода — `main`: [PR #1](https://github.com/usbogdanov-hue/soulane/pull/1) с v1.5 и исправлением Inspector объединён (`61eb550`). Документы организации чатов доступны в `codex/chat-topics`, пока PR #2 не объединён.

## Работа в нескольких чатах

- Перед кодовой задачей определить базовую версию, создать отдельную рабочую ветку и изолированную рабочую копию при необходимости.
- После задачи сохранить результат и заметки через PR. Короткая передача — по шаблону в [общем контексте](CHAT_CONTEXT.md).
- Если два чата меняют один файл, явно передать им ссылки на соответствующие задачи/PR и согласовать порядок изменений.
- Для переноса уже обсуждённого правила или лора записать подтверждённое решение в заметки нужной темы; другой чат восстановит его оттуда.

Разрешение на отправку изменений, данное в одном чате, не следует считать автоматической синхронизацией настроек всех новых чатов. Пользователь может сохранить свою формулировку в пользовательских инструкциях Codex:

> Разрешаю отправлять изменения Сулэйна в публичный репозиторий `usbogdanov-hue/soulane`, создавать рабочие ветки и PR без дополнительного подтверждения.

Это не разрешение на автоматическое объединение PR или изменение доступа к репозиторию.
