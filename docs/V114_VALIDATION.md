# Проверка v1.14 — статистика боя

14 ноября 2026 года, Godot 4.6.3. База — опубликованная v1.13 `fc7552a0`, ветка `codex/v1.14-battle-statistics`; PR #14 на момент начала открыт. Объединение с main не выполнялось.

## Результаты

- Импорт — без ошибок скриптов. Общий прогон: **36/36 файлов, 3464 проверки**, включая новый сценарий **82/82**.
- Статический аудит — **526/526**, **364** ссылки; `git diff --check` проходит.
- После проверки нативного отчёта улучшен контраст текста для чтения; фокус результата запрашивается только внутри дерева сцены, чтобы сохранить старый API Demo.new вне дерева. Повторно выполнены новый сценарий и прежний feedback: **82/82 и 54/54**, без ошибок движка.
- Счётчики проверены на фактическом уроне без overkill, платном промахе, крите/магии, попадании с нулевым уроном, добивании, контузиях и ровно двух собственных пропусках, реальной регенерации у максимума, M, движении и добровольном пропуске.
- Проверены согласованность сумм команд и бойцов, глубокие копии снимков, отсутствие RNG/событий при чтении отчёта и планировании ИИ, однократный учёт выполнения ИИ, неполные составы, павшие, R/T/P и новый принятый бой. Кодек остаётся v4 и не содержит статистики.
- Через реальную сцену и события viewport проверены все вкладки результата, выбор строки, выделение всего текста, ожидание последней анимации, повторное открытие и сброс повтором.

## Нативная проверка

В отдельном XDG-каталоге запущена реальная сцена 3×3. Партия до победы выполнена через существующие методы действий и планировщик, затем вкладки, выбор бойца, выделение текста и возврат к журналу/итогам проверены мышью XTest в окне 1440×900. Это не ручная и не браузерная партия.

Синие победили на шестом раунде. Учтены **17 атак, 3 крита, 3 добивания, 2028 HP урона**, из них 1600 у синих и 428 у красных. Значения совпали с потерями реальных HP всех шести бойцов. Учтены 220 MP расхода, 93 MP регенерации, два применения контузии, два выполненных собственных пропуска, десять перемещений и 21 шаг. В этой партии магия и промахи не выпали; они проверены отдельно детерминированными сценариями движка.

Все шесть строк и подробности помещаются. Отчёт доступен для выделения, его повторное открытие не меняет текст и счётчики. Код принятой подготовки включён с пояснением, что HP/MP, очередь и случайные исходы им не восстанавливаются. Финальный нативный лог без ошибок скриптов, только предупреждение окружения VSync.

## Ограничения

Пять прежних сценариев (`test_duel_v11`, `test_gdd_v09`, `test_matter_v10`, `test_monsters_v14`, `test_v13`) сохраняют прежние сообщения очистки CanvasItem RID / ObjectDB / ресурсов при успешном завершении. Новая статистика не сохраняет промежуточный бой и не воспроизводит RNG.

Полная браузерная партия, сохранность браузерного хранилища после перезапуска и Godot 4.3 не проверены. В managed Sites окружении нет `cua_repl.js`; браузерный preview по Sites skill пропущен. Нативная сцена, экспорт и проверки WebAssembly не заменяют браузерную игру.
