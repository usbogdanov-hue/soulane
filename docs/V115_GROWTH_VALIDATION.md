# Основа v1.15: рост и влияние характеристик

15 ноября 2026 года. База — опубликованная v1.14 `cce04cea`; ветка `codex/v1.15-commanders-magic`. Это подготовка крупного пакета, а не новая Web-публикация: правила новых умений и гибридов ожидают GDD.

## Утверждённые изменения

STR/INT дают +1% физического/магического урона за очко; предел характеристик 45 снят, бонусы урона не выше +90%. Последним уточнением пользователь уменьшил вклад WIS в MDEF с +2 до +1 п.п. за очко для всех командиров. Броня, HP/MP-бонусы характеристик, AGI и регенерация MP сохранены. Итоговая защита ограничивается после сложения компонентов и поправок, включая материю.

Очки за уровни автоматически распределяются по четырём утверждённым долям поверх существующей базы. Целочисленная последовательность сохраняет бюджет и не уменьшает уже полученные очки при повышении уровня. За каждые десять очков пропорции точны. DEX означает AGI. Модель рассчитана для двух воинов и двух магов, но наборы умений магам не назначались.

Текущий редактор показывает очки только для чтения. Кодек v5 проверяет автоматически рассчитанные значения; настоящие v3/v4 проходят историческую проверку и затем перерасчёт с сохранением уровня, брони, материи и книги. Старые v1/v2 и внешняя библиотека v1 поддерживаются.

## Проверки

- Импорт Godot 4.6.3 завершился без ошибок скриптов.
- Итоговый общий прогон: **39/39 файлов, 3741 проверка**. Новые: рост — 60, миграция/кодек — 103, интеграция/сравнение — 85.
- Статический аудит — **549/549**, **383** ссылки на файлы; `git diff --check` проходит.
- Проверены все 3996 сочетаний четырёх архетипов и уровней 1–999: точный бюджет, монотонность, отклонение каждой доли меньше одного очка. Проверены отсутствие расхода RNG и независимость возвращаемых словарей.
- Интеграция проверяет HP/MP, четыре характеристики, бонусы урона, крит, уклонение, защиты по трём физическим типам, MDEF и регенерацию четырёх профилей 30-го уровня. Высокие STR/INT принимаются, потолок бонусов +90% остаётся. На высокой WIS проверены итоговый предел защиты, отрицательные эффекты и материя без преждевременного обрезания вклада WIS.
- Проверены реальный физический/магический урон по коэффициенту +1%, редактор только для чтения, смена уровня с сохранением материи/книги, неполные команды, повтор и чистота каталога. Существующие сценарии материй, ИИ, хранилищ, очереди, контузии и статистики прошли после адаптации ожидаемых характеристик.
- Сравнение 30-го уровня с тяжёлой/средней/лёгкой бронёй рассчитано непосредственно через новые методы профиля Godot и сохранено в [COMMANDERS_LEVEL30.md](COMMANDERS_LEVEL30.md).
- Исторические ручные тесты явно используют отдельные приватные профили с отключённым авторостом. Исходные ресурсы каталога не мутируются. Этот режим сохранён для совместимости модели, а не игрового редактора утверждённых классов.
