Сначала прочитать [общий контекст](../CHAT_CONTEXT.md) и `AGENTS.md` **выбранной версии кода**.

## Что сохранять

Точные ограничения характеристик, защиты, уклонения, крита, материй и контузии перечислены в `AGENTS.md`. Не заменять их историческими формулами из `docs/GDD_MAPPING.md` v0.8.

В v1.5 очередь фиксирована, обе команды управляются вручную, действие одно на ход, контузия пропускает два собственных хода, а победа требует поражения всех противников. Материя, формулы урона и ресурсы монстров взяты из v1.4; их баланс остаётся тестовым.

## Проверки

Для изменений боевой логики запускать подходящие проверки из `tests/test_v13.gd`, `tests/test_monsters_v14.gd`, `tests/test_skills_v12.gd`, `tests/test_turns_v15.gd`, `tests/test_teams_v15.gd` на соответствующей ветке. Выбирать набор по изменению, не объявлять старый результат новым запуском.

## Открытые решения

Окончательная инициатива, утверждение баланса монстров и новые способности пока не согласованы. Предложения записывать отдельно от подтверждённых значений. Перед изменением `battle_demo.gd` учитывать задачи интерфейса.

## Передачи задач

Новые результаты добавлять по шаблону из общего контекста: база, рабочая ветка/PR, изменения, проверки, открытые вопросы.
