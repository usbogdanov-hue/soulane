## Область

Планирование этапов, общий список задач, подтверждённые решения пользователя и зависимости между подтемами. Версии сверяются с `README.md`, `CHANGELOG.md` и фактическим состоянием GitHub.

## Текущее состояние

- Реализация v1.5 с командным боем отправлена в PR #1; статус объединения проверять в GitHub.
- Для основного чата, боевой системы, интерфейса, мира и сюжета, тестирования подготовлены отдельные заметки и стартовые сообщения; сами чаты пользователь создаёт в интерфейсе.
- Новые изменения вести отдельными задачами и PR, сохраняя совместимость существующих механик.

## Открытые задачи и вопросы

- Пользовательская проверка боя v1.5; автоматические проверки её не заменяют.
- Два прежних сбоя Inspector: описание и воспроизведение — в заметках тестирования.
- Следующий функциональный этап после v1.5, окончательная инициатива и баланс монстров пока не согласованы. Не назначать им версию и параметры автоматически.
- Утверждённые материалы мира из прошлой переписки пока не перенесены в репозиторий.

## Решения и передачи

Добавлять сюда только подтверждённые общие решения с указанием даты и задачи/PR. Подробности реализации хранить в заметках профильной темы. Для передачи использовать шаблон в общем контексте.
