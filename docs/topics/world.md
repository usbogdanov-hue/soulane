# Мир и сюжет

Сначала прочитать [общий контекст](../CHAT_CONTEXT.md). Этот файл предназначен для сохранения согласованного лора между чатами.

## Подтверждено

- Название проекта: Сулэйн.
- Проект — пошаговая тактика на гексах.
- Утверждённые сведения о мире, фракциях, именах персонажей и сюжетных событиях из прежней переписки **пока не перенесены сюда**. Их отсутствие в репозитории не доказывает, что пользователь никогда их не обсуждал.

Названия тестовых монстров и значения материй в коде сами по себе не утверждают происхождение существ, устройство мира или сюжетный канон. Кодовые названия «мужчина» и «женщина» не являются именами персонажей.

## Предложения

Новых сюжетных предложений пока нет. Добавлять идеи сюда с явной пометкой «предложение», не выдавая их за ранее принятое решение.

## Материалы для переноса

Согласованные сведения из старых чатов или предоставленных пользователем материалов записывать с источником/датой. Если нужных материалов нет, сформулировать конкретный недостающий вопрос вместо восстановления истории по догадкам.

## Формат записи

```text
Тема: мир / фракция / персонаж / событие
Статус: подтверждено пользователем / предложение / открытый вопрос
Содержание:
Источник или дата подтверждения:
Связь с игровыми механиками:
Задача / PR:
```

Изменение лора, которое требует новой механики или баланса, передавать в основной и боевой чаты как задачу; не менять правила боя в ходе обсуждения сюжета без соответствующей задачи.
